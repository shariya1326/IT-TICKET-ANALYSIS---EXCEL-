# IT-TICKET-ANALYSIS---EXCEL-

Project Overview:
This project analyzes 97,498 IT support tickets to evaluate service desk workload, ticket resolution efficiency, agent performance, and employee satisfaction.
Using Microsoft Excel, I cleaned and standardized the data, analyzed operational KPIs, investigated trends and performance differences, and developed an interactive dashboard to translate the findings into actionable recommendations for IT service improvement.

Business Objective:
The objective was to understand:
- What drives IT support ticket volume?
- Which ticket categories and issue types create the greatest workload?
- How efficiently are tickets being resolved?
- How does agent performance vary?
- Are ticket severity, resolution time, and employee satisfaction related?
- Where should management focus resources, training, or technology investments?

Dataset:
The analysis used the following data:
- IT Tickets: 97,498 ticket records containing ticket details, categories, issue types, severity, priority, resolution time, satisfaction, and related attributes.
- IT Agents: Agent-level information used to evaluate workload and performance.
The data was prepared and organized in Excel before conducting the analysis.

Tools & Excel Techniques:
- Microsoft Excel
- Data cleaning and standardization
- Excel Tables
- PivotTables and Pivot Charts
- Lookup functions 
- Aggregate functions (COUNTIF/COUNTIFS, AVERAGEIF/AVERAGEIFS, SUMIF/SUMIFS)
- Date and text functions
- KPI calculations
- Interactive dashboard with slicers
- Data visualization and comparative analysis

Project Workflow:
1. Data Preparation
-Reviewed, cleaned, and standardized ticket and agent data.
-Structured data using Excel Tables, formulas, and lookup functions for analysis.

2. Ticket Volume & Workload Analysis
-Analyzed ticket demand by category, issue type, severity, priority, agent, and time period.
-Identified high-volume categories, workload distribution, and daily/monthly trends.

3. Resolution Efficiency Analysis
-Evaluated average resolution time across ticket categories, issue types, severity levels, and time periods.
-Identified resolution bottlenecks and areas requiring operational improvement.

4. Agent Performance & Customer Satisfaction
-Compared agents using ticket volume, resolution time, and satisfaction scores.
-Investigated performance variations and potential workload or training improvement opportunities.

5. Interactive Dashboard Development
-Built an Excel dashboard using PivotTables, PivotCharts, slicers, and KPI calculations.
-Consolidated ticket volume, workload, resolution efficiency, agent performance, satisfaction, and operational trends into an interactive view for data-driven decision-making.

Key Findings:
- Analyzed 97,498 IT tickets across service desk operations.
- System: 39,002 tickets (40.0% of total volume).
- Login Access: 29,193 tickets (29.9% of total volume).
- System and Login Access together accounted for 69.9% of all tickets.
- Hardware: 9,733 tickets (10.0% of total volume).
- Hardware had the longest average resolution time at 7.63 days.
- System tickets had an average resolution time of 6.62 days.
- Software tickets had an average resolution time of 5.24 days.
- Login Access tickets had an average resolution time of 0.31 days.
- Overall employee satisfaction averaged 4.10 out of 5.

Business Recommendations:
- Prioritize high-volume categories: System and Login Access accounted for 69.9% of tickets; investigate recurring issues and expand self-service support to reduce repeat requests.
- Address Hardware delays: Hardware tickets had the longest average resolution time (7.63 days); review escalation processes, replacement availability, and operational dependencies.
- Improve System resolution: System tickets represented 40.0% of volume and averaged 6.62 days to resolve; focus on recurring incidents, troubleshooting, and preventive maintenance.
- Optimize resource allocation: Use ticket-volume and agent-level metrics to identify workload imbalances and align staffing with demand.
- Strengthen agent performance: Use resolution and satisfaction metrics to identify training needs and opportunities for process standardization.
- Balance efficiency with satisfaction: Monitor resolution time and customer satisfaction together to ensure faster service also improves the employee support experience.
